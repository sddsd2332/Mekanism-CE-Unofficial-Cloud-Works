# 节点交互与分类后续进度

日期：2026-10-17；分类与环境模块说明更新于 2026-10-20。

## 已实现

- 公共节点视图、编辑/观察双模式 provider 咨询、返回 `null` 后继续尝试及内置回落已存在，当前继续保留。
- 节点和连线视图不再持有可变草稿读引用；动作句柄在观察态、提交期间、退出或草稿替换后失效。
- 连线已拆为 `CloudworksClientLinkView` 与 `CloudworksClientLinkPanelProvider`，不再使用 `kind="link"` 的节点视图；首版 addon 连线面板只读。
- 右侧机器与通道面板合并为独立“节点列表”子窗口，不再永久占用右侧画布。可与状态、三仓等窗口并存；重复打开聚焦原窗口。
- 左侧四个根页签“机器 / 输入输出 / 环境节点 / 辅助节点”始终可见，选中后不隐藏。机器类型为全部、加工、发电、其他及 addon 自声明分类；输入输出类型为全部、输入、输出，已解锁的无限资源归输入。
- 页内为“当前类型”文字与单个切换按钮、搜索框，以及共用同一坐标的 5×6 网格；搜索和筛选共同生效并保留原缓存索引。
- 分类随服务端机器缓存 GUI 快照下发，别名/模板继承；分类不修改节点额度、库存占用或放置权限。
- 分类后的槽位保留原缓存索引，双击、按钮放置、Shift 滚轮调整仍使用原有机器预算规则。
- 机器列表和资源过滤槽位复用动态选中框；升级列表按用户要求保持原生样式。

## 未实现与边界

不能把这一批称为“节点平台全部完成”：

1. 环境页显示下界、海洋、森林、雨和雷暴等已解锁的环境节点。环境原型通过 `withMachineModule` 绑定统一模块声明，详见[机器模块 API](CLOUDWORKS_MACHINE_MODULE_API.zh-CN.md)；新增 addon 节点仍须分别接好授权、执行及客户端可见性，分类本身不会授予放置权限。
2. 辅助节点平台首版已进入产线存档、草稿、蓝图、拓扑、Runtime 和 checkpoint；当前首个内容是 Thermal Expansion 散热器。
3. GUI 布局、滚动裁剪、动态图框及多窗口交互仍须客户端实机确认。

## 辅助节点后续边界

依据 `ai/GLM/CLOUDWORKS_SUPPORT_NODE_SYSTEM_20261014.zh-CN.md`，首版实现采用：

- 火把的持续成本是能量、物品还是受配置封顶的免费效果。
- 散热器最多覆盖 6 个目标，冷却剂从辅助节点输入缓存中选择。
- AREA 使用机器卡片超过一半面积的判定；多个辅助效果按倍率相乘。
- 流体成本不足时回落基础倍率；后续可继续扩展 LINE_WIDE 和更细的成本策略。
- 辅助物品占用上传缓存，移除节点时输入流体回收到回收库存。

## 后续实施顺序

1. 通用 addon 特殊节点继续单独补冻结执行合同。
2. 辅助节点继续扩展更多原型和 LINE_WIDE 目标模式。
3. 进行客户端真实服务器冒烟，确认拖动、端口连线和范围渲染。
