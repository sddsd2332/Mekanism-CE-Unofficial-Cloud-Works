# 云端产出倍率

日期：2026-10-14

## 玩家属性与提升卡

产出倍率属于玩家云端，统一作用于该玩家各产线的普通配方产物。
默认 1 倍，`cloudworks:cloud_output_multiplier_card` 每张提升 1 倍。
卡片复用现有云端卡效果、事务发布、错误提示及消费规则，未激活或达到上限时不消耗。

`config/cloudworks.cfg` 的 `cloudworks.maxOutputMultiplier` 默认 64，允许 1 至 1024，
最多三位小数，需要重启世界／服务器生效。最后一次提升只增加到上限。
下调配置不会删除玩家存档中的成长值；运行和界面使用成长值与服务器上限的较小值。

持久化字段是 `outputMultiplierUnits`，以千分之一为单位，1000 表示 1 倍。
没有该字段的开发存档按 1 倍读取，非法类型、非正范围或超界拒绝。
Java 扩展可以通过 `CloudworksCardEffects.OUTPUT_MULTIPLIER.withAmount(500)` 声明增加 0.5 倍的卡效果。
倍率不属于 `MachineExecutionProfile`，不修改 Mek 原生配方表、workRate 或速度／能量升级公式。

## 输出语义

| 输出 | 规则 |
| --- | --- |
| 普通确定性产物及普通副产物 | 单次基础数量乘倍率，整数部分必出，小数部分独立概率补 1 |
| 概率副产物 | 概率乘倍率，单次成功的整包数量不变；整数部分为保底事件，小数部分再掷 |
| 互斥选择产物 | 候选权重不变，选中产物的数量乘倍率 |
| 显式返还物、守恒转换 | 不受倍率影响 |
| 燃料发电、发电资源返还、衰变、无限资源节点、热量 | 保持原规则 |

普通产物 1 个、倍率 1.5：每次产出 1 个，另有 50% 概率产出第 2 个。
基础概率 60%、倍率 2：每次必定成功 1 次，再有 20% 概率成功第 2 次。
如果一次成功给 4 个，两种结果是 4 或 8 个，不再次把包数量乘 2。
概率和数量不会同时缩放，不产生平方倍率。

合并机器、并行和 workRate 改变实际操作数；倍率逐次作用于产物，不减少输入消耗或改变耗能。
小数采用随机舍入，不保存产出余数。大批处理复用现有独立伯努利批处理器，不用期望值替代随机样本。

## 排除声明

适配器的普通 `output()` 默认表示可倍率的产物，不能自动识别它是否实际上是容器返还。
返还物必须显式声明；不按名称、端口名或相同输入资源猜测。

```java
batch.output(mainProduct);
batch.unscaledOutput(containerDescriptor, 1, "item_output");
// 整份合同守恒：
batch.unscaledOutputs();
```

CrT：

```zenscript
Recipes.create("pack:example", 20)
    .input(Resources.item(inputItem), "item_input")
    .output(Resources.item(productItem), "item_output")
    .unscaledOutput(Resources.item(returnedContainer), "item_output")
    .register(machineItem);
// 守恒配方在 register 前调用 .unscaledOutputs()。
```

内置回旋式气液转换、聚变冷却、锅炉和裂变燃料／冷却合同显式排除；
`energy()`、`decay()` 自动标记整个合同不受倍率影响。
热力系统的直接蒸汽、冷却剂和热量结算不通过普通倍率产物算法。

## Runtime 与恢复

- 云端属性进入冻结快照，tick 不读取配置文件、NBT 或卡片来源。
- 最坏输出空间检查包含倍率、概率溢出和小数可能增加的一个单位。
- 空间不足时不预留输入、不推进随机序号；数量溢出不截断成可执行产物。
- 随机流以玩家 UUID、节点 UUID、稳定配方输出合同、节点持久化序号和输出种类／序号派生，不受其他节点运行顺序影响。
- 节点字段 `outputSequence` 只在操作真正开始时前进；它不是产出余数。
- Operation 保存已抽出的完整产物；断电和堵塞保持同一 Operation，完成时不重新抽取。
- 未真正开始的缺电规划可以丢弃，但同一序号产生相同结果。
- checkpoint、正常停服与重编译恢复节点序号和在途输出，已有 Operation 不套用新倍率。
- 编辑删减导致取消已经开始的操作不会回退序号；蓝图不携带序号或在途产物。

云端状态窗口通过业务包显示有效产出倍率，不让客户端读写存档 NBT。
自动化覆盖不等于真实服务器负载和游戏内交互已验证。
