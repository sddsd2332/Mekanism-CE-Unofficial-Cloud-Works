# 可用升级图标条修复

日期：2026-10-18。

## 问题与修复

用户截图中的“风力高度模块 ×64 / ×3”已经证明上传与入库成功。底部图标条却固定枚举速度、能量两个原生升级，遗漏了所有自定义模块。

- 图标条改为原生速度／能量加服务端下发的可上传自定义升级目录。
- 目录不按库存是否大于零过滤，已注册并绑定物品的模块在上传前也可展示。
- 上方库存列表继续只展示实际持有的类型，零库存目录不产生资产。
- 云端升级窗口和机器节点观察窗口共用同一视图模型。
- 节点窗口按机器接受策略对不支持的自定义升级置灰。
- 支持自定义物品图标、提示、去重与换行；没有物品绑定的未知／纯数据类型不生成空白图标。
- 升级目录的网络数量限制与真实库存“最多 16 种”的限制分离；真实库存限制未放宽。
- 高度、熔岩及第三方物品绑定模块共用同一数据路径，没有按物品名称给界面打补丁。
